# CampusFind – Campus Lost and Found

CampusFind is a simple, responsive web application that helps students report and find lost items on campus.

## Features

- Search for items by name, location, or description.
- Filter items by category.
- Filter items by status: Lost, Found, or Returned.
- Report lost or found items with details.
- Mark items as returned.
- Save item reports in the browser using LocalStorage.
- Responsive design for different screen sizes.

## Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling and responsive design
- JavaScript – Search, filtering, and interactive features
- LocalStorage – Saving item data in the browser

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Note

This is a frontend prototype. Item reports are stored in the browser's LocalStorage and are not shared between different users or devices.
